# Praktikum8

## PENJELASAN

Program ini menggunakan konsep class dalam Python:

1. Atribut

self.data
Menyimpan data mahasiswa dalam bentuk dictionary {nama: nilai}.


2. Method

tambah()
Meminta input nama dan nilai → disimpan ke dictionary.

tampilkan()
Menampilkan seluruh isi data mahasiswa.

hapus(nama)
Menghapus data berdasarkan nama mahasiswa.

ubah(nama)
Mengubah nilai mahasiswa berdasarkan nama.


3. Program Utama

Menggunakan loop while untuk menampilkan menu:

1. Tambah data


2. Tampilkan data


3. Hapus data


4. Ubah data


5. Keluar
